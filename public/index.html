Full Accuracy Backup (.jsonl)

Best choice for safety: Keeps exact dates, UTC timestamps, nulls, arrays, sub-items, and user links.

Use when: You want a complete, 100% perfect copy that can restore your data with zero data loss.
EASY TO READ
📄

Standard JSON File (.json)

Best for reading: A neatly formatted text file that you can open in Notepad or VS Code.

Use when: You want to inspect your documents manually or share with developers.
SPREADSHEETS
📊

Excel / Sheets Tables (.csv)

Best for spreadsheets: Saves your data in tables with columns and rows.

Use when: You want to open collections in Microsoft Excel or Google Sheets.
PASSWORD PROTECTED
🔒

Encrypted Backup (.enc)

Best for security: Locks the whole backup with a secret password.

Use when: You want to upload the backup to cloud storage or send it securely offsite.
